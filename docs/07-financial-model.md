# DataShield India: Financial Model

Illustrative unit economics. Replace every assumption with measured data as you learn.

| Assumption | Value |
|---|---|
| Price per subscriber (INR) | 1,999 |
| Volume Y1 / Y2 / Y3 (subscribers) | 5,000 / 40,000 / 150,000 |
| Variable cost per unit (INR) | 450 |
| Revenue shared out (airline/partner) | 0% |
| Acquisition cost per unit (INR) | 400 |
| Fixed costs Y1 / Y2 / Y3 (INR) | 8,000,000 / 24,000,000 / 60,000,000 |

Run `python finance/model.py` for the projected profit table. Edit `PARAMS` in that file to test scenarios.
